# Кандидат расширения read-only Gateway

Статус: **не интегрирован, не установлен, не готов к применению**. Исходный
Gateway и его контракт в текущей среде недоступны. Нельзя предполагать, что
файл конфигурации Xray совпадает с работающей конфигурацией процесса.

Модуль `tools/belt_gateway_channels.py` не имеет CLI и не принимает от оператора
адреса, порты или команды. Он проверяет соответствие портов активных записей
HUB и loopback inbound/routing Xray, переписывание назначения на локальные
LuCI (80/TCP) и SSH (22/TCP), уникальность и порядок маршрутов до любых
соединений. Затем выполняет ограниченный HTTP GET на `/cgi-bin/luci/` и читает
SSH identification без аутентификации. Результаты раздельные; HTTP-статус не
доказывает работоспособность авторизованного LuCI, SSH banner не доказывает
успешный вход, а heartbeat не проверяется. Отрицательный результат означает
отсутствие подтверждения в момент проверки, не диагноз причины.

Перед подготовкой установки нужно получить и изучить исходный код Gateway и
его модель привилегий; определить доверенный read-only способ получить активные
записи и доказать, что конфигурация соответствует работающему Xray. Нужны
атомарность или повторная проверка mapping при изменениях, ограничения размера
ввода/времени, проверка конкурентных вызовов, redaction, тесты отказов и
интеграционные тесты Gateway на отдельном стенде. Текущий модуль не доказывает
активность конфигурации и не защищает от изменения mapping между проверкой и
подключением. Поэтому его нельзя подключать к production Gateway в этом виде.

После выполнения этих условий подготовить закреплённый проверенный артефакт,
точную интеграцию в существующий allowlist команд, план возврата к предыдущей
версии и получить отдельное разрешение на изменение Belt. Не устанавливать
файлы и не перезапускать Gateway до такого разрешения.
